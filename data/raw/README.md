# Raw data

Original data exactly as received: survey exports, interview recordings and transcripts, scraped reviews.

- Never edit these files. Scripts in analysis/ read them and write to data/processed/.
- This folder is ignored by git (see .gitignore). Only this README is tracked.
- Store raw data where your ethics approval says (often institutional storage), not in a public place.
- Anonymise before any AI reads it: replace names of people and small organisations with codes.
