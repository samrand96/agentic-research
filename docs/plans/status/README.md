# Status files

One file per work package, named after it: `WP1.1-search.md`, `WP2.1-protocol.md`, and so on.
Copy `WP-template.md` to start a new one.

**Why:** the next person — you next week, a co-author, a new AI session or a different AI tool —
reads the plan and the status file and carries on without asking you to explain again.

**Rules**

- Update the file at the end of every working session, before the last commit.
- Write numbers you measured, with where they came from (script or report). No number from memory.
- Newest entry at the top of the log.
- Keep it short. A status file is a logbook, not a report.
