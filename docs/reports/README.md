# Reports

Each report records results, and names the script that produced every number in it, so the
results can be made again.

Suggested reports:

- `cleaning.md` — data received, excluded (with reasons) and kept.
- `results.md` — the analysis from the frozen protocol, then exploratory analyses, clearly labelled.
- `literature-map.md` — themes from the literature review.
- `citation-check-YYYY-MM-DD.md` — output of the `citation-check` skill.

Each report starts with: date, git commit (from `git rev-parse --short HEAD`), scripts used, and data version.
